# Backend

This folder contains backend API implementation for FinSight Chatbot.

Recommended structure:
- `src/routes/` - route definitions and API endpoints
- `src/controllers/` - request handlers and orchestration logic
- `src/services/` - business logic, external API integrations, data fetching
- `src/models/` - database models, schema definitions
- `src/db/` - database connection and migration helpers
- `tests/` - backend unit and integration tests
