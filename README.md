# FinSight-ChatBot

Project structure for FinSight Chatbot.

## Recommended folders

- `backend/` - backend API, controllers, services, database models, tests
- `frontend/` - frontend UI, components, pages, services
- `notebooks/` - exploratory notebooks for data source evaluation and proof-of-concept
- `docs/` - documentation, API design, data source comparison, DB schema
- `data/` - raw and processed datasets, exports
- `scripts/` - automation scripts, data ingestion helpers
